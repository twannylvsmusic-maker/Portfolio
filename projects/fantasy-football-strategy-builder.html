Project Overview

This comprehensive tool solves the biggest pain point in keeper league drafts: knowing which players to keep vs. draft with confidence intervals and risk assessment. Built specifically for keeper leagues (1-5 players kept year-over-year), it addresses the unique challenges that redraft-focused tools don't solve.

🎯 Core Problem Solved

Every draft pick in a keeper league is a keeper vs. draft decision. This tool provides clear recommendations with reasoning, confidence intervals, and risk-adjusted valuations to help commissioners make informed decisions.

Key Features

🎯 Keeper vs Draft Decision Matrix

Clear recommendations (DRAFT, KEEP, WAIT, AVOID) with detailed reasoning and confidence intervals for every decision.

📈 Availability Simulation

Monte Carlo simulation with sentiment adjustments to predict draft availability with uncertainty bounds.

⚡ Sentiment Analysis

Real-time news and social media sentiment tracking with momentum and shock detection.

🧠 WR Success Predictor

Machine learning model predicting rookie WR success (>700 yards + >1000 projected) using NFL Combine data.

🌐 API Integration

Automatic data updates from ESPN and FantasyPros with manual CSV upload options.

⚠️ Risk Assessment

Age-weighted valuations, injury history integration, and team stability analysis for keeper decisions.

Technical Implementation

Architecture

The application uses a modular architecture with separate components for different functionalities:

  • Keeper Matrix Calculator: Core decision logic with risk assessment
  • WR Success Predictor: Logistic regression model for rookie WR analysis
  • Sentiment Analysis: News/social media sentiment tracking and normalization
  • Availability Simulation: Monte Carlo simulation with sentiment adjustments
  • API Scrapers: ESPN/FantasyPros data integration

Decision Logic

The system calculates multiple factors to make keeper vs draft recommendations:

  • Keeper Value: Age-adjusted, injury-weighted projections
  • Draft Value: Availability-adjusted with keeper potential
  • Risk Score: Combined age, injury, and team stability risk
  • Confidence Intervals: Uncertainty bounds for all projections

  2. Upload CSV: Use your own rankings and roster data

Workflow

  1. Upload your current roster (CSV or use sample data)
  2. Initialize WR Predictor (click button in sidebar)
  3. Review Keeper Matrix for decision recommendations
  4. Check Availability Analysis for draft timing
